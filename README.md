# 🎯 Haryana Student Career Guide

Ek **offline, mobile-friendly Hindi career guidance** web app — Haryana ke 10th-class students ke liye jo apni ruchi (interest), marks aur district ke based pe career ke best options janna chahte hain.

> **Ek hi file** — `haryana-student-guide.html` — koi installation, koi server, koi internet connection ki zaroorat nahi. Bas browser me kholo aur chalao.

---

## ✨ Features

### 🎯 Career Guide (करियर गाइड)
- **23 career categories**: Science, Commerce, Arts, Agriculture, IT, Govt Jobs, Defence, Sports, Medical, Teaching, Media, Law, Banking, Fashion, Hotel, Animation, Pharmacy, Aviation, Electrical, Environment, Logistics, Psychology, Beauty
- Student apni **interest tile** select karta hai ya khud type karta hai
- **10th % marks** (30–100) daalne pe 3 levels me classified:
  - **High (75%+)** → top careers
  - **Mid (50–74%)** → mid-tier careers
  - **Low (30–49%)** → entry-level/skill careers
- Har career ke liye: **stream, 3 job options, salary, recommended govt job, next step**

### 📖 Language Help (भाषा सहायक)
- **Hindi→English** aur **English→Hindi** translation
- Word by word **practical usage examples**
- **Explain mode** — concept ko aasan words me samjhata hai
- "Haryana Tip" boxes

### ❓ Free Q&A (सवाल-जवाब)
- **55+ questions** ki built-in database (Haryana-specific)
- Keyword matching — student ka sawaal likho, best answer milega

### 📱 Fully Offline
- Koi external CSS/JS/images nahi — sab ek hi file me
- Haryana flag tricolor bar
- Mobile-first responsive design
- Hinglish + Devanagari mix (aam Haryana students ki bhasha)

## 🚀 How to Use

```powershell
# Bas file kholo
start haryana-student-guide.html
```

Ya browser me file ko drag & drop karo. **Kuch aur setup ki zaroorat nahi.**

### Career Guide Steps
1. **Career Guide** tab me apni interest select karo (ya niche type karo)
2. Apna **10th marks** daalo (30–100)
3. Apna **district** chuno
4. **"Show My Career"** dabao → top career options, govt job suggestion aur next step milega
